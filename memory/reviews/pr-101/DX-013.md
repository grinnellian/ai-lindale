### Deliberate deviation from the issue's config block: `Agent` tool dropped

The issue and plan both list `Agent` in tools; the implementation omits it and the prompt
says so explicitly ("No `Agent` tool — this role does not dispatch subagents"), with the
Self-Orientation SME step rewritten to "consult via mention in your findings" accordingly.
The fixture suite pins the omission (`test_agent_does_not_have_agent_tool`). The reasoning
(researcher is a leaf investigator; findings flow back to the dispatcher) is coherent and
internally consistent. The deviation is documented only in the commit message, not on the
issue — see Minor-3.

### Minor

- **Minor-1 — Read-only Bash discipline dropped from the prompt.** The plan's constraints
  included "read-only Bash commands"; the implemented Constraints section forbids
  Write/Edit/NotebookEdit and issue mutation but never restricts Bash itself, so the agent
  can `git commit`, `rm`, or `echo >` a file without violating any stated rule. Post-
  EPIC-004 the *hard* boundary is the container, but CLAUDE.md still lists prompt-enforced
  restriction as enforcement layer 1, and audit-repo shows the house style (explicit "read
  only, do NOT clone" constraints). One sentence in Constraints — e.g. "Use Bash for
  read-only commands only (`git log/show/diff`, `gh ... view/list`, `ls`, `cat`); never
  mutate files or repo state via Bash" — closes the gap. (`.claude/agents/researcher.md`,
  Constraints section.)
- **Minor-2 — Two explicit ACs have no fixture coverage.** The 18-fixture suite asserts
  tools, signature, initialPrompt, maxTurns, and Self-Orientation, but nothing pins the
  Structured Output Template (AC-6: no grep for "Structured Output Template" or its five
  parts) or the Sandbox Reminder (AC-8). Both sections could be deleted tomorrow and the
  suite would stay green. Two `assert_file_contains` calls would cover them.
  (`scripts/tests/test-researcher-fixtures.sh`.)
- **Minor-3 — Adaptation not recorded where the spec lives.** Issue #13's config block
  (Agent, `disallowedTools`, `background: true`, `permissionMode: plan`) is now stale
  against the implementation; the rationale for each drop exists only in commit c26629e's
  message. Per DX-028 (issue description as authoritative spec), the deviations —
  especially the Agent-tool drop, which is a scope choice, not just an EPIC-004 field
  translation — should be noted on the issue (or the description amended) at PR time so
  the spec and the artifact don't diverge silently.

### Nit

- **Nit-1 — Fixture greps are whole-file, not frontmatter-scoped.** Every tool assertion
  greps the entire agent file for `'  - Tool'`. A future body bullet at two-space indent
  (e.g. a doc list containing `  - Write findings to...`) would spuriously fail the
  negative assertions, and positive assertions could pass off body text rather than
  frontmatter. Scoping to the first `---`...`---` block (one `sed -n '/^---$/,/^---$/p'`)
  makes the suite robust. (`scripts/tests/test-researcher-fixtures.sh`, lines 83–121.)
- **Nit-2 — `grep -q '\-Claude Researcher'`** relies on `\-`, which is undefined in POSIX
  BRE (works in practice on macOS/GNU grep). `grep -q -- '-Claude Researcher'` or
  `'[-]Claude Researcher'` is portable. (test file, line 132.)
- **Nit-3 — Unescaped dots in grep patterns** (`CLAUDE.md`, file-path assertions) match
  any character; harmless here but the sibling suites share the habit. (test file,
  line 73.)

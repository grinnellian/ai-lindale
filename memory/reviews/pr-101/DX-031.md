## Findings by severity

### Blockers

### Major

### Minor
- **M1 (drift, outside this diff):** `researcher.md` keeps the legacy `### Context` footer alongside its
  Self-Orientation section, duplicating the memory-review instruction and violating the DX-031 fold-in
  convention. One-paragraph deletion; belongs in a follow-up or the next doc sweep, not a DX-031 revert.

### Nits
- **N1:** `dev.md:46` — "Confirm your current branch **and worktree location** (`git branch --show-current`)"
  cites a command that shows only the branch, not the worktree location. `git rev-parse --show-toplevel`
  or `git worktree list` would back the second half of the sentence.
- **N2:** `templates/sme.md:34` says "or a slash command" where `sme-bootstrap.md` Step 6 always generates
  a concrete `/​<name>` command — `/{{AGENT_NAME}}` would be precise and consistent with the core agents'
  phrasing.
- **N3:** With `initialPrompt: /tpm` (etc., from DX-033) firing the command file on `--agent` launch, the
  command text "Review CLAUDE.md and memory/* files" now duplicates Self-Orientation steps 1-2 on both
  invocation paths. Harmless belt-and-suspenders, but the command files could be slimmed to defer to the
  agent prompt's checklist.
- **N4 (tracking):** `audit-repo.md` has no Self-Orientation section, only the legacy `### Context` footer.
  Out of scope here per the implementer, but no follow-up ticket for it surfaced in issue #57 or the
  tracker search — worth a TPM breadcrumb so it doesn't get lost (it's now the *second* agent, with
  researcher's footer, diverging from the pattern).

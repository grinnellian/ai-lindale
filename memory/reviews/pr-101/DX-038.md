## Findings by severity

### Blocker
None.

### Major
None.

### Minor

- **M1 — Tracker used as end-of-run handoff, not the live tracker the convention mandates.**
  autodev.md:16-17 says "Create it at the start of a run, update it as tickets move through the
  state machine." The actual artifact (`memory/autodev-state-2026-07-06.md`) was written once at
  session end (`15dc066`) and contains handoff state (gate, next wave, gotchas) rather than
  per-ticket state-machine progression (which ticket is mid-dispatch, which subagent is
  running). The durable-pickup half of the convention is demonstrated; the crash-resilience half
  — the failure mode the rule explicitly targets ("labels alone go stale") — is not: a mid-run
  crash before `15dc066` would have left no tracker at all. Either practice should tighten or
  the convention text should honestly describe checkpoint-plus-handoff usage.
- **M2 — Label-mapping follow-up pointer is dangling.** The original commit tracked the
  follow-up "under DX-039 (routing config)"; DX-039 subsequently landed routing *without* label
  mapping, and the stub was reworded (in the DX-039 commit) to "still a follow-up. See
  DX-038 / #89" (`templates/team-config.yml:25-26`). #89 is the ticket PR #101 closes — once it
  merges, no open ticket tracks label-mapping configurability. The session tracker itself flags
  DX-005 (#5, team-config system) for re-scoping; the stub should point at whatever ticket ends
  up owning this, or a new one should be filed before #89 closes.

### Nit

- **N1 — `main` hardcoded in the three-dot rule.** autodev.md:113 gives the literal command
  `git diff main...HEAD`. AC-1a's "project-neutral" bar arguably applies file-wide; downstreams
  on `master`/`trunk` get a subtly wrong literal. The adjacent `gh pr diff` alternative is
  branch-agnostic, so impact is low. Suggest "`git diff <default-branch>...HEAD`" or leading
  with `gh pr diff`.
- **N2 — Issue #89 hygiene.** Both AC checkboxes in the issue body remain unchecked and there is
  no signed implementation comment on the issue (repo convention: agents sign issue comments;
  #89 has zero comments). Housekeeping for the TPM before/at merge of PR #101.
- **N3 — Inconsistent wrapping style within autodev.md.** The DX-038 Memory section is
  hard-wrapped at ~78 columns while every Rules bullet (including the three DX-038 ones) is a
  single long line. Cosmetic; a normalization pass could ride along with the next edit.

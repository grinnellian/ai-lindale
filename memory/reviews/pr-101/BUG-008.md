## Findings

### Blockers
None.

### Major
None.

### Minor

1. **AC2 has no regression test for the upgrade path.** The scenario the AC names — a project
   adopted under the pre-fix installer (only architect/tpm/dev command symlinks present) being
   re-run and picking up `autodev.md` — is guaranteed by mechanics (glob + `link_managed`'s
   missing→link branch) and I confirmed it manually, but no test in
   `scripts/tests/test-adoption.sh` encodes it. `test_idempotent` re-runs the *new* installer
   twice, which is a weaker property. A test that pre-creates only the three legacy symlinks and
   asserts `autodev.md` appears after one run would pin AC2 permanently.

### Nits

2. **Stale user-facing text in install.sh.** The closing message (`scripts/install.sh:202`)
   still says "Run /architect, /tpm, or /dev to start" and the generated linglink README
   heredoc (`:187-188`) still says "Core agents (architect, tpm, dev) are symlinked" — even
   though the installer now ships `/autodev` (this ticket) and all agents (BUG-009). The very
   command this bug was about is still invisible in the installer's own output.

3. **`test_command_symlinks` is now subsumed** by `test_all_framework_commands_symlinked`
   (`scripts/tests/test-adoption.sh:144-150` vs `:152-165`). Harmless duplication, and it doubles
   as a legacy-name regression check, but worth a comment or consolidation. Related pre-existing
   weakness (not introduced here): the legacy loop tests (`test_agent_symlinks`,
   `test_command_symlinks`) lack `|| return 1` inside the loop, so under `if`-context execution
   only the last iteration's status counts. The new BUG-008 test got this right.

4. **Adoption guide wording drift.** `docs/adoption-guide.md:31` — "After this, `/architect`,
   `/tpm`, and `/dev` commands are available" — omits `/autodev` and the other now-installed
   commands. (The migration section's three-command enumeration at `:187-189`/`:204` is
   historical and fine.)

## Correctness notes

- Empty-glob safety: with no `*.md` matches the literal pattern would iterate once; the
  `[ -f "$cmd_file" ] || continue` guard handles it (same pattern as the agent and skill loops).
- Self-host mode: the whole symlink block (`scripts/install.sh:126-165`) is skipped, so the new
  glob cannot clobber framework-source command files. `is_self_host` keys off agents only —
  pre-existing design, unaffected.
- Integration with later branch work is clean: BUG-009's agent glob and FEAT-011's skills loop
  both explicitly mirror this fix's pattern (comments at `install.sh:127-129`, `:148-152`), and
  BUG-009 reused the same test shape. No later commit reverted or weakened the BUG-008 change.
- `sync.sh` has no hardcoded command list; it delegates to install.sh (`scripts/sync.sh:19`).

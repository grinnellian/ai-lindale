## Correctness Assessment

- **Glob loop (install.sh:130-136):** `nullglob` is not set, so an empty agents dir would leave the literal pattern in `$agent_file`; the `[ -f "$agent_file" ] || continue` guard handles this correctly (same idiom as the BUG-008 commands loop). `basename` + relative `src`/`dest` construction is identical to the proven commands path.
- **Override protection (`link_managed`, install.sh:52-86):** untouched by this change. The regular-file branch (line 69-81) skips with message unless `--force`. Verified by running: a pre-existing project-owned `researcher.md` survives install, is counted in `skipped:`, and `--force` semantics are unchanged.
- **Self-host interaction:** `is_self_host` (install.sh:92-103) still keys on exactly architect/tpm/dev being regular files. In the real framework repo all agents are regular files, self-host triggers on the core three, and the entire symlink pass (including the new glob) is skipped — correct. The `setup_self_host` test helper only converts the core three to regular files, leaving researcher/audit-repo as symlinks, which still triggers self-host detection; behavior is consistent (see nit N4).
- **Red/green discipline:** clean. Test commit first, verified failing against pre-fix install.sh; fix commit turns it green with no test edits in the fix commit.
- **Test adequacy:** the glob test is self-strengthening (any future agent added to `.claude/agents/` is asserted automatically via the updated `setup_project`, which now copies all `*.md` agents into the fake framework). Explicit researcher/audit-repo asserts pin the reported bug even if the repo's agent set changes. Override, idempotency, self-host, force, wrong-symlink-refresh paths all retain coverage.

### Minor
- **M1 — Stale linglink README text shipped downstream.** The heredoc install.sh writes to every downstream `.claude/README.md` (install.sh:186-188) still says "Core agents (architect, tpm, dev) are symlinked from the Lindalë framework." Post-BUG-009 that list is wrong — all framework agents (currently 5, incl. researcher and audit-repo) are symlinked. The doc-sweep commit (9672c16) fixed the in-repo trees but missed this generated, downstream-facing text. Suggest: "Framework agents (everything in .ai-lindale/.claude/agents/) are symlinked...". Non-blocking; behavior is correct.

### Nit
- **N2 — Override test doesn't assert the skip message.** The AC parenthetical says "(skipped with the standard override summary line)". `test_project_agent_override_preserved` asserts preservation but not the `skipped ...` output or `skipped:` summary count; that output is only asserted for architect via `test_override_skip_message`. Coverage-by-proxy through the shared `link_managed` path is reasonable, and I verified the message by running, but a one-line grep in the new test would pin the AC exactly.
- **N3 — Override test was green at the test-only commit.** At 734823b only the glob test failed (56/1). Pre-fix, the hardcoded loop never touched `researcher.md`, so the preservation assert passed vacuously; it only exercises the intended skip path post-fix. Fine as a regression guard (and the AC's "red test first" names only the symlink test), but worth noting the test never demonstrated a failure mode.
- **N4 — Self-host misdetection blast radius grows slightly.** Pre-existing, documented behavior: a downstream that real-file-overrides all three of architect/tpm/dev is misdetected as self-host and gets NO symlinks. Post-BUG-009 that now silently withholds researcher/audit-repo (and future agents) too, rather than just the core set. Out of scope for this ticket; flagging for a possible follow-up on the `is_self_host` heuristic.
